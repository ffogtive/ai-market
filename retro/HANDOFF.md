## 검증된 핵심 발견
- AI로 일하는 사람의 작업 기록은 git이 아니라 **프롬프트**에 있다.
- 원본 로그의 절반이 잡음(에이전트 간 지시, 대화 이어하기 요약, 세션 중복) → 필터 반영됨.
- 데이터가 여러 기기에 흩어짐(맥·GPU 서버·클라우드) → 여러 호스트 병합 지원.
- `claude -p`로 API 키 없이 요약 가능(9/23 데이터로 품질 확인, 약 73초).
- **첨부와 함께 보낸 지시가 맥락이 가장 풍부한데, 그 본문을 통째로 잃고 있었다**(9/25 발견·수정). Codex 원본 헤더는 `## My request:`인데 코드는 `## My request for Codex:`만 찾아서, 매칭 실패 시 본문을 버리고 `[첨부 파일]`만 남겼다. 서버 실데이터 8일치에서 **내 지시 166건 중 47건(28%)이 내용 0**. 사진을 붙여 보내는 지시(기획·전략 지시가 여기 몰린다)를 요약이 못 보고 있었다.
- 사진은 프롬프트 안에 `<image path="/tmp/…/1-사진-1.jpg">` 태그로 들어와 **경로에 파일명이 담긴 채 LLM으로 전송**되고, 600자 예산을 잡아먹어 정작 지시를 잘랐다 → `[사진 n장]`만 남긴다.
- Codex 로그의 일부 텍스트가 리터럴 HTML 엔티티(`&#x20;` 한 서버에서 21,996회)로 저장된다 → `html.unescape()`.
- **"분류가 엉성하다"는 대개 수집 문제다.** 위 두 수집 버그를 고치자 문구 신호의 `기타`가 **36% → 12%**로 떨어졌다(지시 34→47%, 질문 17→27%). 규칙을 더 정교하게 만드는 것보다 입력을 고치는 게 효과가 컸다.
- **요약 LLM은 숫자를 주면 반드시 해석한다.** 주간 요약이 "프로젝트 전환 73회 … 컨텍스트가 계속 끊김"이라고 썼다(프롬프트에 "점수·평가 금지"가 이미 있었는데도). 자동 실행이 함께 도니 A→B→A는 하루의 기본 모습(실데이터 하루 66회)이라 해석할 것이 없다 → **전환 수를 LLM에 주지 않는다**(페이지에는 중립 숫자로 표시).
